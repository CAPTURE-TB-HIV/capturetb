# capturetb: Econometric cost functions for estimating TB outpatient visit unit costs

Econometric cost functions for estimating TB outpatient visit unit
costs, developed at LSHTM for the CAPTURE (Cost Analysis for
Prioritizing TB and HIV Resources Efficiently) project.
