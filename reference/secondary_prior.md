# Constructs a power prior for the effect of being a secondary hospital outpatient visit costs, based on the WHO-CHOICE estimate.

Constructs a power prior for the effect of being a secondary hospital
outpatient visit costs, based on the WHO-CHOICE estimate.

## Usage

``` r
secondary_prior(a0 = 0.1)
```

## Arguments

- a0:

  Scaling factor for the power prior.
