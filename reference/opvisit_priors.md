# Constructs a list of priors using power priors for urban and public ownership and a weakly informative prior for the other coefficients.

Constructs a list of priors using power priors for urban and public
ownership and a weakly informative prior for the other coefficients.

## Usage

``` r
opvisit_priors(n_weak_priors)
```

## Arguments

- n_weak_priors:

  Number of additional weakly informative priors to include.
