# Constructs a power prior for the effect of being a primary hospital outpatient visit costs, based on the WHO-CHOICE estimate.

Constructs a power prior for the effect of being a primary hospital
outpatient visit costs, based on the WHO-CHOICE estimate.

## Usage

``` r
primary_prior(a0 = 0.1)
```

## Arguments

- a0:

  Scaling factor for the power prior.
