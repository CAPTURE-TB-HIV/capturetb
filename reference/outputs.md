# List unique output types in raw data

Returns all unique output types found in the ValueTB data.

## Usage

``` r
outputs()
```

## Value

A character vector of unique output types.

## Examples

``` r
outputs()
#>  [1] "op_diagnosticvisit"            "op_treatmentvisit_ltbi"       
#>  [3] "op_treatmentvisit_dot"         "op_screeningvisit"            
#>  [5] "op_vaccinations"               "op_coughtriage"               
#>  [7] "op_treatmentvisit_mdr"         "op_monitoringvisit"           
#>  [9] "op_screeningvisit_mch"         "op_adherencesupportvisit"     
#> [11] "op_treatmentvisit"             "op_visitforinjection"         
#> [13] "op_follow-upvisit"             "op_visitforcollectingmedicine"
```
