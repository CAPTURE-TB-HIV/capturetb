# Constructs a power prior for the effect of public ownership on outpatient visit costs, based on the WHO-CHOICE estimate.

Constructs a power prior for the effect of public ownership on
outpatient visit costs, based on the WHO-CHOICE estimate.

## Usage

``` r
prior_public_ownership(a0 = 0.1)
```

## Arguments

- a0:

  Scaling factor for the power prior.
